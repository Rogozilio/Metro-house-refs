# Metro house refs

Moodboard of the references behind the Metro city catalogue of We Are Destroyers: 89 buildings in 7 districts and the central park, and 228 props, as a pan-and-zoom board (one collage per district; the park has its own) or as a list. Residential buildings show the stylised 3/4 refs sent to Phantasm (November 2026). Where no reference had a 3/4 view, a Blender render of the in-game model comes first, followed by the SlopMachine (or GeneratedArt) reference views the model was built from. 58 catalogue props have no reference and show the render only.

Static site for GitHub Pages: `index.html`; buildings in `img/` (board thumbnails `img/b/`, list thumbnails `img/t/`, views `img/v/<id>/`), props in `img/p/` (`b/`, `t/`, extra refs `v/<id>/`).

After replacing an image in place, run `python tools/stamp_images.py` before committing: it gives every replaced image a `?v=` stamp in `index.html`, because Pages lets browsers keep an image for 10 minutes.
